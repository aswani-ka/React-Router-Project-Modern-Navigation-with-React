# 🚀 React Router Project

A modern React application built with **React Router** to implement smooth, client-side navigation.  
This project demonstrates routing basics including **nested routes**, **dynamic routes**, **layouts**, and **error pages**—all implemented in a clean and scalable architecture.

---

## ✨ Features

- 🔗 Client-side routing with React Router v6  
- 📄 Nested routes & shared layouts  
- 🧭 Dynamic route parameters  
- ⚠️ 404 Not Found page  
- 🎨 Responsive UI  
- ♻️ Reusable components and clean folder structure
